# Interface Web (4203E5MO) - Démos et exemples de code

Ce dépôt rassemble les exemples de code et les démonstrations réalisés pendant les séances de cours.

## Structure du dépôt

Les exemples sont organisés par sujet ou par numéro de séance/semaine. Parcourez les dossiers pour retrouver le code présenté en démonstration :

- **`css/demo...`** : demo css...
- **`html/demo...`** : demo html...
- **`js/demo...`** : demo js...

## Utilisation

Pour récupérer le code sur votre poste :

```bash
git clone <URL_DE_CE_DEPOT>
```

Pour mettre à jour le code déjà cloné :

```bash
git pull
```
